# 哈喽卧得 · Gratia

**替一个去不了现场的人，把一件小事完成在那个地方。**

---

## 有些地方，你一时去不了

老家巷口那棵桂花树，今年开花了没有。

妹妹的毕业典礼，你在外地赶不回去。

十年前你和某个人在一座桥上说过一句话，今年你想再听一次那里的风声。

想看一眼，却隔着几千公里。你能做的，好像只有在朋友圈里写一句"可惜"。

**哈喽卧得做的事很简单：帮你找到一个正好在那里的人，替你去一趟。**

你写下地点和想说的话；一个恰好在那座城市的人接下它；他到现场，录一段、拍一张、或者把你的话写成一张卡片；然后交到你手里。

「远方」不是这个产品要克服的障碍，是它存在的全部理由。

---

## 它怎么运作

### 如果你想请人帮忙

1. **写下心愿** — 选一个场景，搜索或直接输入地点（任何地方都行，不限城市），写下你想说的话，选择你希望收到照片、视频还是手写卡片。
2. **等待审核** — 每一条心愿都由人工看过才会公开。这一步会花一点时间，但它保证了这里不会变成一个什么都能发的地方。
3. **有人接下** — 心愿出现在「帮助」页，愿意前往的当地人会响应你。你从响应的人里选一个。
4. **聊清楚细节** — 在应用内私聊。什么时间去、想要什么样的画面、要说哪一句话。
5. **收到交付** — 他到了现场，把东西交回来。你确认收到，这件事就完成了。
6. **要不要讲出来，你决定** — 完成之后，你可以单独选择把它变成一个公开的故事，也可以永远不。

### 如果你想帮别人

打开「帮助」页，看看有谁想去你所在的地方。

替一个陌生人拍下他惦记的那条街、那棵树、那扇窗——这件事本身就挺好的。你不需要有什么特别的技能，只需要正好在那里，并且愿意走这一趟。

## 我们坚持不做的事

这些不是还没做，是**决定不做**：

| | |
| --- | --- |
| **不涉及任何金额** | 应用内没有支付、没有内购、没有赏金。这不是一个跑腿平台。 |
| **不收集联系方式** | 双方只在应用内对话，不交换微信或手机号。事情做完，联系也就结束了。 |
| **不使用定位** | 城市和地点都由你自己写下。我们从不申请定位权限。 |
| **没有点赞数和评论** | 首页不是第二个信息流，也不制造虚假的热闹。 |
| **完成 ≠ 公开** | 心愿完成之后，是否公开成故事由发布者单独决定，且仍需人工审核。 |

我们相信，一个只做少数几件事的产品，比一个什么都做的产品更值得托付。

---

## 关于安全

这件事的本质是：你把一个对自己有意义的地方，托付给一个陌生人。所以安全不是附加功能。

- **发布的内容先经人工审核**，通过后才会被其他人看到。昵称与头像同样如此。
- **任何一段对话都可以举报**。举报会由人工查看并处理，通常在 24 小时内响应。
- **任何一段对话都可以屏蔽**，立即生效，不需要等待。屏蔽后对方无法再联系你，但记录会保留——你随时可以取消，也随时可以拿它作为凭据。
- **运营不会随意查看用户对话**。只有当一条具体的举报提交之后，相关会话才会被打开。
- **我们不持有你的联系方式**，因此也无从泄露。

## 关于名字

「哈喽卧得」是 **Hello World** 的音译——每个程序员写下的第一行代码，向世界打的第一声招呼。

英文名 **Gratia**，拉丁语，意为"感谢"与"恩惠"。

一个人替另一个人走了一趟，不图什么。这大概就是我们想做的那件事。
