## 一句话

替一个去不了现场的人，把一件小事完成在那个地方。发布者写下地点与想说的话，当地人接下并到现场完成，通过 App 交付。

**双方相隔千里、永远不会见面**——这不是限制，是整个产品的前提，也是许多设计决定的出发点。

## 架构

```
iOS (SwiftUI, iOS 18+)          运营台 (Next/vinext → GitHub Pages)
        │                                    │
        └──────────► Cloudflare Worker ◄─────┘
                            │
                    ┌───────┴───────┐
                   D1              R2
              (业务数据)      (交付文件 / 头像)
```

| 层 | 技术 |
| --- | --- |
| 客户端 | SwiftUI，iOS 18+，仅 iPhone |
| 服务端 | 单个 Cloudflare Worker（TypeScript） |
| 数据库 | D1（SQLite），迁移 0000–0011 |
| 对象存储 | R2（交付文件、头像） |
| 运营台 | Next/vinext 静态导出 → GitHub Pages |
| 登录 | Sign in with Apple |
| 定时任务 | Cron，每 15 分钟检查待审队列 |

**没有常驻服务器，没有容器，没有 CI**。部署是一条 `npm run deploy:cloudflare`，它会先构建、再部署、再跑 D1 迁移。

## 几个值得说明的设计决定

**账号层是 provider-neutral 的。** `account_identities` 按 `(provider, provider_subject)` 唯一，现有 `apple` 与 `wechat` 两个 provider，加 Google 只是加一行。这是 2026 年 7 月转向微信小程序时的产物，回到 App Store 路线后几乎原样复用——没有因为换客户端重做数据模型。

**交付文件用随机能力令牌访问，不可枚举。** 文件本身在 R2，URL 带一次性生成的 token，不依赖登录态，也无法遍历。

**账户删除会撤销 Apple 登录令牌。** Apple 对支持账户删除的 App 有此硬性要求，审核会实测。已端到端验证：重新登录 → `refresh_token` 落库 → 删除账户 → Apple ID 设置里 App 消失。

**API 走自有域名。** 此前用 `*.workers.dev`——Cloudflare 的共享测试子域，在中国大陆被整体污染，导致国内不挂代理时**全部** API 不可用（不只是登录，浏览、发布、私聊一起失效）。现绑定 `api.hanselzhang.com`。这只解决「连不上」，不解决「慢」：Cloudflare 免费版在国内没有节点。

**iOS 端不含任何运营密钥。** 运营台的 PIN 只存在于本机与 Worker secret。

## 内容安全机制

四类内容需人工审核后才对外可见：心愿正文、昵称与头像、公开到首页、举报处理。

私聊与一对一交付**不做事前审核**，靠举报与屏蔽兜底。运营读取被举报会话**必须由一条具体举报触发**（接口要求传 reportId），不能凭空翻阅用户对话。

屏蔽即时生效、可撤销；屏蔽后会话与历史记录保留，仅禁止发送新消息——站内私聊是双方唯一接触面，那段记录也是唯一能证明发生过什么的地方。

> 这套机制对应 App Store 审核指南 1.2 对 UGC 应用的四项要求：事前过滤、举报机制、屏蔽能力、公开联系方式。指南原文点名「以线下实物或服务交付告终的服务」，本产品正属此类——因此**不能把发布心愿改成免审**，除非先补上自动过滤。

## 测试

| | 数量 | 方式 |
| --- | --- | --- |
| 后端 | 44 | Node test runner，真 SQLite（`node:sqlite`）驱动真实 Worker |

后端测试**加载的是构建产物** `dist/server/index.js` 而非源码——直接跑 `node --test` 会测到上次构建的旧代码，必须用 `npm test`（它会先 build）。这个坑真实浪费过一小时。

## 已知技术债

- **推送通知**：服务端与六个触发点已实现并有测试，客户端未接入，APNs 密钥未配置。
- **无多语言**：iOS 端 381 条、服务端 139 条中文硬编码，未抽 `Localizable.strings`。
- **无暗色模式**：全 App 锁定浅色（`.preferredColorScheme(.light)`）。`DesignSystem` 的颜色全是写死的浅色字面量，补齐需逐屏校对对比度。
- **内容审核全人工**：没有关键词或自动过滤。用量上来后应改为「自动过滤命中才进人工队列 + 事后抽查」。
- **国内访问慢**：服务器在境外。根本解决需 ICP 备案 + 境内服务器，涉及社交/UGC 类额外资质。
- **心愿场景与交付形式写死在客户端**：「生日祝福 / 口播视频 / 手写卡片」等仍是中国语境。
