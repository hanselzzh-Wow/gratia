## 三、描述（Description，≤4000 字符）

```
有些地方你一时去不了。

老家巷口的那棵树，朋友婚礼的现场，某座城市里你和某个人约定过的桥。想看一眼，却隔着几千公里。

哈喽卧得做的事很简单：帮你找到一个正好在那里的人，替你去一趟。

【它怎么运作】

1. 发布心愿
   写下城市、具体地标、场景和你想说的话，选择你希望收到照片还是视频。

2. 人工审核
   每一条心愿提交后都进入待审核状态，由运营人工看过之后才会公开。没通过审核的内容不会出现在任何公开列表里。

3. 匹配同城的人
   审核通过后，心愿会出现在"帮助"页，由愿意前往的当地用户响应。运营人工确认后派单。

4. 收到交付
   对方到达现场完成后，通过 App 把照片或视频交付给你。你确认满意，这个心愿就完成了。

【也可以反过来】

如果你就住在别人想去的地方，可以在"帮助"页看看有谁需要。替一个陌生人拍下他惦记的那条街，是件挺好的事。

【关于隐私】

· 联系方式从不公开。它只提供给运营和实际履约所必需的环节。
· 公开的心愿只显示城市、地标、场景和正文，不含联系方式，也不含精确位置。
· 我们不使用系统定位。城市和地标都是你自己手写的。
· 登录使用"通过 Apple 登录"，我们只接收 Apple 提供的匿名标识，不请求你的姓名和邮箱。
· 你可以随时在"我的 → 账户"里直接删除账户，不需要联系客服。

【关于内容安全】

所有用户发布的内容都要经过人工审核才会公开。App 内设有"帮助与安全中心"，可以举报骚扰、违法或不安全的内容。运营可以拒绝、暂停或取消任何一单。

【关于费用】

App 内不收取任何费用，也没有应用内购买。心愿里的"感谢金"只是你申报的心意程度，用来帮助匹配，不由 App 代收。实际怎么结算，由运营在完成后与双方另行确认。

【当前阶段】

这是 1.0 的第一个版本，功能刻意做得很少：没有关注、没有私信、没有评论，也没有伪造的热度数字。浏览不需要登录，只有发布心愿或响应帮助时才需要账户。

如果你在使用中遇到问题，欢迎通过下方支持页面联系我们。
```
