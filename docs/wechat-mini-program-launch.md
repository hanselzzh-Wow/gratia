# 哈喽卧得微信小程序 0.1：上线候选与平台交接

更新：2026-07-19。本文是 `WX-001` 的上线材料，不替代微信后台实际显示的要求；所有带“控制台核实”的项目必须由已认证主体在提交前逐项完成。

## 已交付的本地候选

- 原生微信小程序工程位于 `miniprogram/`，根目录 `project.config.json` 可被微信开发者工具导入。当前 `touristappid` 仅供导入/本地预览，上传前必须在工具内绑定真实 AppID，不能提交伪造身份。
- 固定底栏保留 1.0 的五个目的地：首页、搜索、发布、帮助、我的；这是小程序对 iOS 浮动 Dock 的唯一导航适配。图标为随工程分发的 Lucide SVG，图形与布局不伪装成 iOS 系统控件。
- 首页、搜索与帮助仅请求真实 `GET /api/wishes` 公开待匹配数据；没有数据时使用诚实空态，不把 Preview/演示故事当作线上内容。
- 发布严格保留三步和第 1 步无右侧“地点”字样。最终提交/帮助响应调用 `wx.login`，把一次性 code 发送到 Worker；Worker 服务器端换取 OpenID 并签发本服务会话。
- “我的”包含微信登录、本人发布/响应、旧编号+联系方式兼容查询、交付读取、发布者确认完成与账户删除。交付通过账户授权的 Worker 流式端点下载到小程序临时文件后预览，不显示或复制 R2 能力 URL。

## 账户、隐私与安全设计

1. 账户数据模型是 `users` + `account_identities(provider, provider_subject)` + 哈希会话表；微信只是第一个 provider，未来 Apple 可新增 identity，业务订单通过 `user_id` 归属。
2. 小程序只知道本服务短期会话 token。微信 `AppSecret`、`session_key`、运营 PIN、Cloudflare 凭据、R2 能力 token 均不写入小程序、构建产物、日志或公开错误。
3. 游客可浏览公开数据和使用旧编号兼容查询；发布、响应、本人记录、交付与确认完成强制账户授权。旧网页/iOS 的无登录 API 保持兼容，不能据此在小程序伪造用户身份。
4. 小程序内“删除账户”会撤销全部会话、删除微信 identity、标记账户已删除，并将其订单/响应的称呼与联系方式匿名化。为履约状态、投诉和财务/安全审计保留去标识订单记录；删除后的身份不能访问旧记录，联系方式不曾是登录凭据。
5. 联系方式只传给运营/履约所需服务端流程，绝不出现在公开列表。运营台仍只走 PIN 保护的 `/api/admin/**`，小程序不含运营入口、PIN 或管理接口。

## 小程序所需最小权限与数据清单

| 数据或能力 | 目的 | 触发时机 | 是否在公开页展示 |
| --- | --- | --- | --- |
| 微信登录临时 code | 服务器建立本服务账户 | 用户发布、响应或主动登录 | 否 |
| 服务端 OpenID/本服务 userId | 归属本人记录、防冒领 | 登录后服务端处理 | 否 |
| 称呼、联系方式 | 人工审核、撮合与履约联系 | 发布或响应时用户填写并勾选同意 | 否 |
| 城市、地标、场景、心愿内容 | 审核、公开待匹配与履约 | 发布时用户填写 | 仅审核通过的业务内容 |
| 交付照片/视频临时文件 | 向已登录发布者展示履约结果 | 发布者主动打开交付 | 否 |

本版本不请求定位、通讯录、相册写入、麦克风、摄像头或微信昵称/头像。若后续新增任何能力，必须先重审隐私文本、最小权限和微信控制台声明。

## 人工审核、内容安全与投诉

- 所有新发布先进入 `pending_review`，运营人工检查可执行性、隐私、骚扰、人身安全、未成年人、违法与侵权风险；通过后才成为 `matching` 并在帮助页公开。
- 出现骚扰、威胁、色情、违法、未成年人或真实地址/联系方式泄露时：立即拒绝/暂停新单，必要时取消既有订单，保存最小审计记录并由运营人工联系受影响方。
- 小程序“关于/客服”应在上传前由主体补入真实可联系渠道与投诉处理时效；不要在代码、公开仓库或截图写私人手机号、运营 PIN 或交付链接。

## 微信控制台与发布清单（均待控制台核实）

1. 使用可承担该类服务的微信小程序主体创建 AppID；确认小程序名称、服务类目、主体资质和内容审核要求。个人主体可否覆盖真实撮合/履约业务必须由控制台实际类目与规则决定，不能根据本地构建猜测。
2. 在开发设置配置 Worker 的 HTTPS 服务域名，并确认该域名的备案、证书、解析与主体要求；开发环境与正式域名分别核实。`https://haluowode-mvp.hanselzzh.workers.dev` 不能被默认视为已满足微信服务域名条件。
3. 在 Worker 私密环境设置 `WECHAT_MINI_PROGRAM_APP_ID` 和 `WECHAT_MINI_PROGRAM_APP_SECRET`，绝不写入 `wrangler`、Git、客户端或日志；完成后在预览环境实际测试 `wx.login → /api/auth/wechat`。
4. 在微信后台按当前版本填写用户隐私保护指引、收集清单、隐私政策 URL/文本、客服/投诉渠道、账户删除入口说明、测试账号与审核说明。内容必须与上表及实际行为逐条一致。
5. 用真实受邀体验者完成：登录、发布、人工审核、帮助响应、运营派单、交付、确认完成、账户删除；检查拒绝、网络失败、重复提交、登录取消、注销后会话失效和公开页隐私。
6. 上传体验版并完成预览/真机测试后再提审。只有微信后台显示审核通过并成功发布，才能对外表述“已上线”。
