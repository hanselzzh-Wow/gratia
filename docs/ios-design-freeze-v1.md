# iOS MVP 设计冻结 v1

状态：`FROZEN v1 / v2.1 visual`
冻结日期：2026-07-18（Asia/Shanghai）
来源：`CL-001` 设计交接与 Codex 评审

本文件是 SwiftUI MVP 的视觉与交互实现基线。后端字段、状态和隐私边界仍以 `docs/ios-api-contract.md` 为唯一依据；设计图中的示例内容不得覆盖真实契约。

## 评审结论

`CL-001` 首轮 8 组交付通过，接受其 v2 信息结构和 Design System，并冻结为 v2.1：

- 保留暖白页面底色、近黑主文本/主按钮、1px hairline、零投影、克制圆角和 4/8pt 网格。
- 品牌蓝 `#2F6FE0` 用于链接、选中、进度当前态、焦点和 App Icon；不改成全屏蓝色或大面积渐变。
- 晨光金 `#B9791F` 只用于感谢金和少量心意强调，不用作大色块。
- 主按钮继续使用近黑胶囊，保持行动层级明确；发布 Tab 可以使用品牌蓝增加识别度，但仍保持标准 Tab Bar 行为。
- 语义字体和 Dynamic Type 是实现要求，设计稿中的 pt 数值只作为视觉比例参考。

冻结依据：

- 已人工查看启动、首页、附近列表、发布确认和进度详情导出图。
- 1x 页面导出为 393×852，3x 为 1179×2556，App Icon 为 1024×1024。
- `app-icon.svg` 通过 XML 结构检查。
- 首页/附近 HTML 都包含完整 5 栏；附近 PNG 中部分浅灰 Tab 图标视觉很弱是导出对比度问题，SwiftUI 实现必须保持可辨识度与系统语义图标。
- 页面结构没有公开发布者身份、联系方式或精确住址。

## Design Tokens

### 颜色

| Token | 值 | 用途 |
| --- | --- | --- |
| `ink900` | `#0A0A0A` | 主文本、主按钮 |
| `ink700` | `#3A3A3A` | 次要文本、表单标签 |
| `ink500` | `#767676` | 辅助文本、时间 |
| `ink300` | `#B5B5B5` | 占位和禁用文本；实现时需验证对比度 |
| `hairline` | `#E6E6E6` | 描边、分隔 |
| `hairlineSoft` | `#F0F0F0` | 骨架、弱分隔 |
| `canvas` | `#FFFFFF` | 卡片、输入框、Tab Bar |
| `canvasWarm` | `#FEFCF9` | 页面底色 |
| `accent` | `#2F6FE0` | 交互强调与品牌 Icon |
| `accentSoft` | `#EAF1FC` | 选中浅底、当前态光晕 |
| `gold` | `#B9791F` | 金额文字 |
| `success` | `#2E7D4F` | 成功文字 |
| `successSoft` | `#EAF5EE` | 成功浅底 |
| `danger` | `#B23B2E` | 错误、未通过 |
| `dangerSoft` | `#FBEDEA` | 错误浅底 |

实现时颜色必须以 SwiftUI Color Asset 或集中 Token 表达，并在浅色模式下验证 WCAG/iOS 可读性；首版可不交付完整深色模式，但不得把颜色散落硬编码到页面。

### 字体与布局

- Large Title 28/34、Title2 22/28、Title3 18/24、Headline 17/22、Body 17/24、Subhead 15/20、Footnote 13/18、Caption 12/16。
- SwiftUI 优先 `.largeTitle`、`.title2`、`.headline`、`.body`、`.subheadline`、`.footnote`、`.caption` 等语义样式。
- 内容水平边距 20pt；密集列表可用 16pt；触控区域至少 44×44pt。
- 圆角 `sm=8`、`md=12`、`lg=16`、`pill=Capsule`。
- Tab Bar、导航栏、表单底栏用 Divider 表达层级，不用阴影。

## PM 裁决

1. **App Icon**：选择品牌蓝底 + 白色线形标志作为 MVP 主图标。纯黑底版本保留为实验稿，不作为当前构建资源。
2. **重复文件**：以 `40_Tracking_Home` 与 `41_Tracking_Detail` 为权威；`40_Progress_Home`、`41_Progress_Detail` 标记 `DEPRECATED`，本轮不删除，避免误删并行产出，但实现不得引用。
3. **视觉方向**：接受 v2，但通过品牌蓝 Icon、发布 Tab 和交互状态保留“天空/抵达”的品牌感，形成 v2.1；不恢复大面积渐变和投影。
4. **首次引导**：不进入可试用 MVP P0。首次打开直接进入首页，降低实现与测试范围。
5. **我的/账户**：MVP 不伪造账号体系。只做未登录的信息页，包含产品说明、安全、隐私、帮助和版本信息；登录态等后端有账户能力后再设计。

## 实现门槛

- 五栏名称和顺序固定：首页、附近、发布、进度、我的。
- 所有联网页面覆盖加载、空、错误、重试；提交覆盖禁用、提交中、防重复和失败后保留输入。
- 任何联系信息都不得出现在公开列表/详情；私有进度页也不得显示响应者联系方式。
- AX3 Dynamic Type 下不截断核心文案；可点击区域不小于 44pt；错误不能只靠颜色。
- 候选代码现有固定字号、Mock、全局可变数组和假延时不是冻结设计的一部分，必须替换。
