App Icon 三个原创方向

按 docs/ios-visual-direction-v3.md 的硬性约束制作：无 Emoji、无文字、无渐变，每个方向最多一个底色 + 一个前景色，20–60pt 仍需清晰，黑白剪影可识别。三个方向从不同角度抽象"远方、抵达、在场"，不复制 WhatsApp / X / Threads / Instagram 的具体商标图形，只借鉴"单一符号、极简轮廓、小尺寸可辨识"的原则。

颜色测试说明：每个方向都用旧品牌蓝 #2F6FE0 渲染一次；方向 A（推荐方案）额外并排提供一个克制的替代色 #3E6B92（降低饱和度、略带暖调的蓝灰色）供对比——旧蓝更鲜亮醒目，替代色在暖白背景上更柔和、更不易和界面里的品牌蓝强调色互相争夺注意力。是否更换以此对比为准，本稿不额外扩展第三种配色。

方向 A · 路径与抵达点

推荐

一个小圆点（远方的人、心愿的起点）与一段渐次变粗的弧线相连，弧线的另一端是一个更大的实心圆点（抵达、在场、被完成的心意）。整个图形是一次连续的手势——从小到大、从远到近，直接对应"心愿从远方出发，被恰好在场的人接住"。三个关键词（远方/抵达/在场）被压缩进同一个连续动作里，而不是三个并列的符号，这是推荐它作为主方案的原因：足够抽象、不会被认成地图应用或聊天软件，同时在 20pt 依然能看出"一头小一头大、中间一条弧线"的核心结构。

方向 B · 相遇（两个重叠的圆）

备选

两个大小不同的实心圆部分重叠，较大的圆在重叠处留出一圈极细的底色缝隙，让较小的圆始终保持完整、清晰地"浮"在上面。抽象表达两个原本不相关的人（发布者与恰好在场的响应者）在同一个地点相遇。识别度高、几何极简，但风险是容易让人联想到通用的"用户群组/社交"图标语言，原创性弱于方向 A。

方向 C · 地标旗帜

备选

一根竖直的杆，底端是一个实心圆点（落地、扎根、在场），杆的上段伸出一面简单的三角旗（心意被"标记"在这个具体地点，像插旗一样宣告"这里有一个心愿"）。三个关键词里"在场"表达最直接，但"远方"和"抵达"的动态感较弱，更偏静态的"标记一个地点"，识别度依赖旗帜三角形，在 20pt 时旗面容易和杆糊在一起，是三个方向里小尺寸风险最高的一个。
