图标系统 v3

不使用任何 Emoji。所有图标为统一风格的单色线性图标：22×22 基准网格，1.6pt 描边，圆角端点，参照 WhatsApp / X / Threads 的极简单色图标语言。实现时优先直接使用等价的 SF Symbol（见每个图标下方标注），本页 SVG 仅供设计预览和未覆盖场景的备用矢量源。

决策记录：首轮 CL-001/CL-002 设计稿中用 Emoji（🔒🔔🎬 等）作为图标占位符，用户明确要求"App 里不要出现任何一个 Emoji"。本图标系统替换所有占位符，属于 v3 视觉修订的一部分，见 CL-002-claude-design.md 附录说明。

使用规范

1. 统一描边 1.6–1.8pt，端点和转角均为圆角（stroke-linecap/linejoin: round），与品牌图形（纸飞机 Logo）的线条语气一致。
2. 图标颜色跟随文字语境色（currentColor），不单独上色；唯一例外是发布 Tab 的强调填充圆和状态类图标（如成功勾选可用 success 色）。
3. 列表行图标统一 20×20 或 22×22，行内不与文字重叠、不使用方形色块背景（除 Tab Bar 发布键的强调填充圆）。
4. SwiftUI 实现优先直接使用对应 SF Symbol（已在每个图标下标注），保证系统级 Dynamic Type、无障碍朗读和深色模式自动适配；本页 SVG 仅在 SF Symbol 无法满足自定义构图（如品牌 Logo、图标化插画）时使用。
